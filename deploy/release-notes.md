## v0.2.12

改进实时刷新、日志与终端性能，修复长连接和子进程退出时的资源回收。

- 容器、镜像、卷、网络和栈数量通过一条共享 SSE 更新；仅发送最新状态，不保存或回放事件历史。操作后的刷新复用连接，并等待新的真实查询结果。
- CPU、内存等动态主机指标不再使用短时结果缓存。无可见订阅时停止采样；主机身份与运行时自检仍保留有界短时缓存。
- 栈概览只读取真实配置并复用一次列表查询，不再逐栈查询容器详情；刷新不会覆盖未保存的 YAML 和 `.env` 草稿。
- 日志和容器终端点击后才连接，关闭、切页、隐藏或退出登录时释放。日志自动重连；终端恢复前台后由用户手动重连，不自动创建 shell。
- 日志使用稳定行标识和按帧合并绘制，保留有界显示窗口；终端等待 xterm 消费输出，避免高速输出积压渲染任务。
- Linux 下命令正常退出或取消时安全清理进程组，避免后台后代泄漏和 PID 重用误杀。日志与终端最多同时连接 16 路，达到上限时返回具体提示。
- 服务停机先取消长连接，再等待共享采样和请求退出；会话结束取消在途请求，阻止旧响应继续操作。
- 启用前端严格类型及未使用代码检查，移除生产代码中的测试入口，补充并发、取消、日志渲染和实时刷新回归测试。
- 调整 Apple System 明暗主题下的日志、终端与窄屏布局，长名称不再撑开页面。

### 升级

先备份栈目录（包含 `.dockge-data`）和业务卷，再更新面板镜像。内部路径仍为 `/opt/stacks`、`/app/data`，端口仍为 `5001`；原有数据挂载继续兼容。不自动迁移或删除业务数据。

```text
makeshit/dockge:0.2.12
ghcr.io/dockge-go/dockge:0.2.12
```

两个镜像均提供 `linux/amd64` 和 `linux/arm64`。GHCR 私有包需要 `read:packages` 凭据，匿名部署可使用 Docker Hub。

支持单机 Docker Engine 与 Docker Compose v2，不提供 Kubernetes 部署。非 Linux 平台使用安全单进程取消，不保证后台后代整组清理。
