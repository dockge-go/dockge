## v0.2.9

包含 Docker Compose 全面整改，并修复登录限流计数跨服务实例共享的问题。单实例限流阈值保持不变，增加重复运行和实例隔离回归验证。

- 部署范围统一为单机 Docker Compose，移除集群清单和节点专用逻辑。
- 仪表盘、资源列表、部署输出、日志和容器终端统一使用 SSE；系统指标直接采集真实内核数据。
- 修复暂停容器操作、多标签镜像删除及已停止容器的卷、网络引用判断。
- 删除栈先列出清理范围，再删除专属容器、卷、网络、镜像和栈目录；共享、external 资源与栈外路径保留并说明原因。
- 修复部署输出、日志恢复、终端输入及尺寸调整，补充编辑与部署的回归测试。
- 整理部署、备份、密码重置和 OIDC 说明，更新真实界面截图；默认发布镜像示例改用 Docker Hub。
- CI 在失败时输出可定位的测试与构建错误摘要，保留原始退出状态，不跳过检查。

### 升级

先备份栈目录（包含 `.dockge-data`）和业务卷，再更新面板镜像。内部路径仍为 `/opt/stacks`、`/app/data`，端口仍为 `5001`；原有数据挂载继续兼容。不自动迁移或删除业务数据。

```text
makeshit/dockge:0.2.9
ghcr.io/dockge-go/dockge:0.2.9
```

GHCR 私有包需要 `read:packages` 凭据，匿名部署可使用 Docker Hub。
