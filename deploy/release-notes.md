## v0.2.11

修复长连接、请求取消和限流边界，降低多窗口使用时的重复采样与栈列表刷新开销。

- 仪表盘 SSE 连接共享主机、资源采样与快照编码；慢连接仅保留最新快照，不累计历史帧。最后一个连接退出后取消查询，重连不会收到旧的在途快照。
- 修复请求取消、子进程回收和数据操作边界，保留运行时真实错误明细。
- JSON 请求正文增加独立读取期限，避免慢请求长期占用连接，不影响 SSE 长响应。
- 限制登录用户名长度，使用定长限流键；修复限流桶过期清理、满容量访问和并发计时顺序。
- 栈列表采用线性合并，保留未保存的 YAML、`.env` 草稿及部署输出。
- CI race 检测覆盖全部 Go 包，补充长连接、并发与编辑草稿回归测试。
- 修复系统采样缓存测试对机器速度的依赖，明确验证缓存到期前后及并发读取行为；生产数据仍由真实内核采集。

### 升级

先备份栈目录（包含 `.dockge-data`）和业务卷，再更新面板镜像。内部路径仍为 `/opt/stacks`、`/app/data`，端口仍为 `5001`；原有数据挂载继续兼容。不自动迁移或删除业务数据。

```text
makeshit/dockge:0.2.11
ghcr.io/dockge-go/dockge:0.2.11
```

GHCR 私有包需要 `read:packages` 凭据，匿名部署可使用 Docker Hub。
